# بروزرسانی نسخه اپ

برای هر انتشار جدید، این دو فایل باید با هم تغییر کنند:

1. `package.json`
   - مقدار `version` را به شماره نسخه جدید تغییر بده.

2. `.version-changes.json`
   - داخل آرایه `releases` یک ورودی با نسخه‌ای برابر `package.json` اضافه کن.
   - تغییرات کاربرمحور همان نسخه را داخل `changes` و به فارسی بنویس.
   - اگر تغییر قابل نمایش نداریم، `changes` را خالی بگذار؛ خود ورودی نسخه باید وجود داشته باشد.
   - ورودی نسخه‌های قبلی را حذف نکن تا تاریخچه داخل اعلان قابل مشاهده بماند.

فایل `public/version.json` هنگام build به‌صورت خودکار تولید می‌شود و نباید دستی ویرایش شود.

نمونه:

```json
{
  "releases": [
    {
      "version": "2.0.5.3.2",
      "releasedAt": "2026-06-07T18:00:00Z",
      "changes": [
        "بهبود سرعت بارگذاری داشبورد",
        "رفع خطای نمایش فاکتورهای فروش"
      ]
    },
    {
      "version": "2.0.5.3.1",
      "releasedAt": "2026-06-06T18:45:46Z",
      "changes": []
    }
  ]
}
```

اگر نسخه `package.json` در `.version-changes.json` ثبت نشده باشد، build متوقف می‌شود تا تغییرات نسخه قبلی اشتباهی منتشر نشود.

اپلیکیشن هر ۶۰ ثانیه فایل `version.json` را بدون cache بررسی می‌کند. اگر نسخه منتشرشده جدیدتر باشد، نوار بروزرسانی نمایش داده می‌شود. بعد از بارگذاری نسخه جدید، همان نوار موفقیت بروزرسانی را نشان می‌دهد و تغییرات نسخه جاری و نسخه‌های قبلی از همان‌جا قابل مشاهده است.
