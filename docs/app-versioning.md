# بروزرسانی نسخه اپ

برای هر انتشار جدید، این دو فایل باید با هم تغییر کنند:

1. `package.json`
   - مقدار `version` را به شماره نسخه جدید تغییر بده.

2. `public/version.json`
   - مقدار `version` باید همان نسخه `package.json` باشد.
   - مقدار `releasedAt` تاریخ انتشار است.
   - داخل `changes` تغییرات همان نسخه را به فارسی بنویس.

نمونه:

```json
{
  "version": "2.0.5.0",
  "releasedAt": "2026-05-20T21:30:00+03:30",
  "changes": [
    "بهبود سرعت بارگذاری داشبورد",
    "رفع خطای نمایش فاکتورهای فروش"
  ]
}
```

اپلیکیشن هر ۶۰ ثانیه فایل `version.json` را بدون cache بررسی می‌کند. اگر نسخه منتشر شده از نسخه‌ای که کاربر در حال استفاده از آن است جدیدتر باشد، اعلان بروزرسانی بالای صفحه نمایش داده می‌شود.
