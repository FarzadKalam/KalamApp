# قرارداد منوی اصلی

- نوار آیکون دسکتاپ ۸۰ پیکسل و پنل متصل به آن ۲۶۰ پیکسل است؛ اندازه‌ها و تشخیص حالت از `utils/sidebarLayout.ts` می‌آیند.
- فقط مسیر داشبورد `/` فضای پنل و فاصلهٔ امن را رزرو می‌کند. سایر مسیرها عرض خود را حفظ می‌کنند و منو روی محتوا باز می‌شود.
- زیرمنوهای دسکتاپ با هاور و دسترسی صفحه‌کلید به چپ باز می‌شوند؛ موبایل منوی لمسی با زیرمنوهای درون‌خطی دارد.
- کلیک بیرون در حالت پوششی و Escape منو را می‌بندند؛ عملیات روی داشبورد نباید باعث جابه‌جایی ناگهانی ابزارک‌ها شود.
- فهرست‌ها همچنان از دادهٔ فیلترشدهٔ مجوز و پلن در Layout ساخته می‌شوند؛ پنل منبع مستقل ماژول‌ها ندارد.
- حرکت نرم فقط به فضای داشبورد محدود است و تنظیم کاهش حرکت سیستم رعایت می‌شود.
- بررسی انتشار ۱۴۰۵/۰۸/۲۲: آزمون‌های قرارداد و مرورگر در GitHub اجرا می‌شوند؛ نتیجهٔ انتشار پس از بررسی ثبت خواهد شد.
