1. روی دامنه واقعی بررسی کن که `/sitemap.xml` با `Content-Type: application/xml` پاسخ می‌دهد.

7. پس از جمع‌شدن داده، گزارش‌های Pages، Performance و Core Web Vitals را هفتگی بررسی کن.
