# ممیزی Hard-code بستهٔ نصب اختصاصی

**دامنهٔ ممیزی:** فایل‌های داخل `installer/`، Compose اختصاصی و کپی توابع Edge موجود در `installer/docker/volumes/functions/`. کد اصلی مخزن تغییر نکرده است. URLهای API عمومی ارائه‌دهندگان در این گزارش Secret محسوب نمی‌شوند؛ مقدار Secret چاپ یا ثبت نشده است.

## نتیجه

در لایهٔ Compose و Frontend، دامنهٔ مشتری و Secretها از فایل تنظیمات بیرون Repository می‌آیند. بااین‌حال چند Function هنوز به fallback یا allow-list دامنهٔ مرکزی وابسته‌اند. بنابراین بسته برای بررسی و ادامهٔ نصب آزمایشی آماده است، اما برای Production کامل نیست. رفع قطعی موارد پرریسک مستلزم مجوز جداگانه برای تغییر Functionها یا حذف/غیرفعال‌کردن ماژول‌های مربوط است؛ تغییری در کد اصلی یا رفتار Cloud عادی انجام نشده است.
